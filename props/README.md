# props

装扮（挂件）目录。仓库**不附带任何素材**（版权原因），帽子、眼镜、围巾之类的 PNG 放这里。

## 用法

设置卡片「外观」页 →「戴帽子…」选一张图，程序会自动复制到本目录并给角色戴上；
下面的滑杆调大小与左右/上下位置。「摘掉」即取消。常用配置项：

| 键 | 说明 |
| --- | --- |
| `props.hat` | 挂件文件名（本目录下）；留空 = 不戴 |
| `props.hatSize` | 挂件宽度 = 角色宽度 × 这个比例（默认 0.55） |
| `props.hatX` / `props.hatY` | 挂件中心在角色盒子里的相对位置，0 = 左/上边，1 = 右/下边 |

## 说明

- 建议用透明底 PNG；位置是相对角色盒子的比例，所以换角色、改缩放都不会跑偏。
- 本目录内容已被 `.gitignore` 忽略：素材版权由使用者自行负责，不要提交到仓库。
